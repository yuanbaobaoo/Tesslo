# 兼容回归语料库（架构 §8）

独立于引擎目录的测试固定件——引擎绞杀者重写 / 内部 fixtures 变动不影响本库。

## 来源与分层

| 层 | 内容 | 状态 |
| --- | --- | --- |
| 官方固定件 | scratch-vm 上游 `test/fixtures/*.sb3`（24 个：default / events / 监视器 / 注释 / 云变量边界 / 损坏样本等） | v1 已入库（本目录） |
| 官方示例 | scratch.mit.edu 编辑器内置示例 ≥ 20 个（覆盖九类积木、扩展、监视器） | 待补：下载脚本 + 版权复核 |
| 社区抽样 | 真实项目 50–100 个（小/中/大分层，含常用扩展；不含个人信息素材） | 待补 |

## 扩充规则

1. 入库文件只读：测试不得写回或依赖绝对路径；
2. 新增语料随 PR 提交，并在提交说明列覆盖点（积木类别 / 扩展 / 规模）；
3. 语料与断言分离：断言在 `tests/compat-*.test.ts`，语料仅是数据。
