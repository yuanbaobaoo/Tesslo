# 迭代方案索引（P1–P6）

可单独执行；方案内不再分期，任务清单即执行顺序。

| 编号 | 方案 | 内容 | 规模 | 前置 |
| --- | --- | --- | --- | --- |
| P1 | [作品管理](P1-works.md) | 首屏项目列表 + 可见项目目录 + 快照版本 + 导出 .tess / .sb3 工程文件与 .html 执行文件 | L | 无 |

| P5 | [素材本土化](P5-assets-l10n.md) | 素材中文化 + 中文搜索 + 本土主题包 | S–M | 无 |
| P6 | [超级终端积木](P6-super-device.md) | 跨设备：手机手柄、手表传感器 | XL | P1、P4 |

## 顺序与并行

- **P1 → P2**：P1 是地基（存储可靠是工具的信任底线）；P2 与任何方案
  无耦合，P1 执行期间可随时并行插入。
- **P3**：独立，排 P2 后。
- **P4**：内部先传感器（小、独立可交付）后 AI（共用桥骨架与真机
  摸底流程）。
- **P5**：纯内容型，无代码耦合，可在任意迭代期间碎片时间并行推进。
- **P6**：最后做。依赖 P1（作品库）与 P4（传感器数据协议）；
  开工前先做分布式权限调研 spike。

规模口径（单人开发）：S ≤ 2 周，M = 2–4 周，L = 4–8 周，XL ≥ 8 周。
