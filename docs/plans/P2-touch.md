# P2：触屏交互

> 优先级 2 · 规模 S–M · 前置：无 · 可与任何迭代并行（与 P1 并行最佳）

## 目标

把鼠标优先的编辑器改造为平板优先：**单指（不接鼠标）完成
"拖积木 → 插入 → 改参数 → 运行"全部核心操作**，体验流畅到儿童
能独立上手。

## 现状与锚点

- 目标设备 tablet / 2in1（`module.json5` deviceTypes）。
- scratch-blocks 是 Blockly fork：触摸有基础支持，但命中区小、
  手势面向鼠标——拖拽易误触、无长按菜单、撤销重做藏在顶部菜单。
- gui 顶部工具栏触屏可达性尚可，但撤销 / 重做目标太小太远。

## 技术设计

所有改动挂 `TESSLO_TOUCH` 行为开关（编译期常量或 gui 设置项），
独立模块、可整体摘除，控制与上游的 diff。

1. **命中区与拖拽目标放大**：scratch-blocks workspace options 的
   drag target 尺寸、touch 命中阈值、connection 检查半径——
   先调参后改码。
2. **双指平移 / 捏合缩放工作区**：zoom / move 配置逐项验证触摸
   表现，缺失手势在 blocks 层补。
3. **长按上下文菜单**：优先验证 scratch-blocks 长按弹
   ContextMenu 的能力，缺失则自实现（touchstart ≥ 500ms）；
   菜单项：复制 / 删除 / 帮助。
4. **撤销 / 重做悬浮按钮**：gui 层右下角悬浮组，目标 ≥ 48vp，
   `TESSLO_TOUCH` 下显示。
5. **palette 触摸滚动**：动量滚动 + 分区吸顶。

后续滚动清单（不单列迭代，按价值逐项捡起）：磁性吸附预览增强、
拖到角落删除区、参数专用软键盘（数字/角度/颜色）、积木多选手势、
舞台手势（双击绿旗全屏）、压感笔（2in1）。

## 任务拆解

- [ ] 真机摸底：录屏 10 个核心操作，产出痛点清单与量化基线
      （误触次数 / 完成时长），改造前后对照
- [ ] `TESSLO_TOUCH` 开关骨架（gui 设置项 + CSS/逻辑分支）
- [ ] 命中区与拖拽目标调参（纯配置，逐项真机验证）
- [ ] 双指平移 / 捏合缩放
- [ ] 长按上下文菜单（复制 / 删除 / 帮助）
- [ ] 撤销 / 重做悬浮按钮
- [ ] palette 动量滚动
- [ ] 儿童可用性测试：5 名真实用户 15 分钟独立完成 3 积木程序
- [ ] 摸底指标复测，量化改进写入本文件

## 验收标准

- [ ] 单指完成核心流程全程不碰鼠标，无明显误触
- [ ] 5 名儿童 15 分钟内独立完成一个 3 积木程序（观察记录存档）
- [ ] 关闭 `TESSLO_TOUCH` 后行为与现状一致（可摘除性）

## 风险与备注

- 手感是迭代出来的：每项改动必须真机验证，"能点"不算完成
- 与 P3 双视图共用面板 / 软键盘类 UI 基建，可复用组件
