# P3：积木-代码双视图

> 优先级 3 · 规模 M–L · 前置：无 · 明确不做：代码→积木反向导入

## 目标

侧滑"开发者视图"：查看当前积木生成的 JavaScript（可选 Python），
运行时逐行高亮。给"学积木是为了学编程"的用户一条平滑阶梯。

差异点：Scratch 官方设计哲学明确拒绝积木→文本代码桥，这是与官方
正面不同路线的功能，也是家长 / 学校最认的卖点之一。

## 现状与锚点

- blocks 数据在 scratch-vm 内为 JSON（opcode + inputs + fields），
  codegen 输入即项目序列化结构。
- 运行高亮信号源：gui 已有 blockGlow 机制（线程当前执行块），
  同一信号可驱动代码面板高亮。
- 代码生成是纯本地计算，不碰平台层与网络，独立模块即可。

## 技术设计

### codegen 模块（独立包）

- 新建 `packages/tesslo-codegen`（workspace 包，不进 scratch-vm
  源码树，上游包零污染）：
  - 输入：项目 JSON（targets / blocks / variables / lists）
  - 输出：带源块标记的 JS 代码 + `片段 → 源块 ID` 映射表
  - 核心覆盖：事件 / 控制 / 运动 / 外观 / 声音 / 变量 / 列表 /
    运算 / 自定义积木；未覆盖积木输出注释占位
    （`/* TODO: 未支持的音乐积木 */`），不静默丢失
- **语义保真原则**：生成的代码 = VM 会执行的代码。浮点、字符串
  比较、边界行为与 VM 一致，不为"代码好看"牺牲保真
- 参考：社区 `sb-edit`（MIT）证明 JSON→代码可行；实现自研，
  协议干净
- 可选：Python emitter——同一骨架换输出器，教学风格映射
  （`repeat 10` → `for i in range(10)`），面板加语言切换

### GUI 面板

- 编辑器右侧侧滑面板，默认隐藏，入口名"开发者视图"（不暗示
  "代码才是真编程"，保持积木第一）
- 等宽字体代码区 + 积木类别折叠导航
- 运行高亮：codegen 映射表 + blockGlow 信号，当前块对应行高亮
  滚动跟随，偏差 < 100ms

## 任务拆解

- [ ] `packages/tesslo-codegen` 包骨架 + 项目 JSON 解析
- [ ] 九类核心积木的 JS emitter + 源块 ID 标记
- [ ] 快照测试：≥ 10 个官方示例项目生成代码，快照入版本库
- [ ] GUI 侧滑面板 + 开发者视图入口
- [ ] 运行高亮联动（blockGlow 信号 → 面板行高亮）
- [ ] 性能验证：双视图开启帧率下降 < 5%
- [ ] （可选）Python emitter + 语言切换
- [ ] 未覆盖积木占位清单收敛（目标核心积木 100%）

## 验收标准

- [ ] 官方示例项目（≥ 10 个）生成代码可读、核心积木覆盖 100%
- [ ] 高亮与绿旗执行同步，偏差 < 100ms
- [ ] 双视图开启不影响运行性能（帧率下降 < 5%）
- [ ] 切换视图 / 关闭面板无崩溃、无状态污染

## 风险与备注

- 保真优先：VM 行为"怪异但真实"的语义照实生成，不做美化
- 扩展积木（含 P4 传感器等）先注释占位，按需再补
- 与 P2 的面板 / 软键盘 UI 基建可互相复用
