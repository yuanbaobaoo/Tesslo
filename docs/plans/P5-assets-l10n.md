# P5：素材本土化

> 优先级 5 · 规模 S–M · 前置：无 · 纯内容型工作，可在任意迭代期间碎片时间并行

## 目标

素材库对中文儿童"叫得出、搜得到、用得上"，并可通过本土主题包持续
扩充而主包体积不涨。

## 现状与锚点

- 素材 1328 个文件已离线入库（`apps/host/ohos/assets/fetched/`），
  AssetServer（回环 20114）提供，无外网依赖。
- 素材元数据在 `scratch-gui/src/lib/libraries/`（sprites /
  backdrops / sounds JSON），当前为英文；scratch-l10n zh-CN 有
  部分词条可复用。

## 技术设计

1. **中文化**：素材元数据 zh-CN 词条补齐（名称 / 分类 / 标签），
   走 scratch-l10n 现有管道；教师审校术语（"backdrop=背景"等
   儿童用语统一）；词条键控，语言切回英文不串词。
2. **中文搜索**：名称拼音 / 别名本地索引（构建期生成映射表），
   运行时前缀 + 包含匹配，纯本地无网络。
3. **主题包机制**：manifest（素材清单 + 分类 + 词条 + 来源记录）
   + 素材文件（CC0 / 自绘自录）；增量安装到设备素材目录，
   AssetServer 加透 `static/packs`，主包不涨；设置页管理
   （安装 / 卸载 / 占用）。
4. **首批主题包**（各 20–40 素材）：剪纸与皮影、生肖与节日、
   民族乐器音效、家乡地标背景。

## 任务拆解

- [ ] 元数据盘点：三库词条数量与缺译清单
- [ ] zh-CN 词条补齐 + 教师审校
- [ ] 拼音 / 别名索引生成脚本 + 库内搜索接入
- [ ] 中英文切换回归验证
- [ ] 主题包 manifest 格式 + AssetServer `static/packs` 支持
- [ ] 主题包安装 / 卸载 / 占用管理 UI
- [ ] 首批 2 个主题包制作（版权审计 + 入库）
- [ ] 主包体积对照（增量前后一致）

## 验收标准

- [ ] 库内全部名称 / 分类显示中文，"熊猫""烟花"等搜索可命中
- [ ] 搜索响应 < 100ms（1328 素材全量索引）
- [ ] 语言切回英文显示正常，无串词
- [ ] 主题包安装后库内可见可用，卸载干净；主包体积不变

## 风险与备注

- 版权红线：一律 CC0 / 自绘自录，来源记录入 manifest，
  不确定来源不收
- 翻译机器稿仅作初稿，教师审校定稿
- 可选不承诺：本机 AI 生成素材（依赖 P4 能力成熟度）
